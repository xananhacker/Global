# Muhamad Mbaraka Abdul — Portfolio Website

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — website content and structure
- `style.css` — responsive styling
- `script.js` — mobile navigation and current-year footer
- `assets/Muhamad_Mbaraka_Abdul_CV.pdf` — downloadable CV

## Run locally
Open `index.html` in a modern browser. No build tools or package installation are required.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `muhamad-mbaraka-portfolio`.
2. Upload the contents of this folder (not the ZIP file itself) to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The public URL will appear in the Pages settings.

## Publish with Vercel
1. Push this folder to a GitHub repository.
2. Sign in to Vercel and import that repository.
3. Choose **Other** as the framework preset if prompted.
4. Leave the build command and output directory empty; the site is static.
5. Deploy.
